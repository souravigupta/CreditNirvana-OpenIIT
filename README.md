# CreditNirvana – Open IIT Data Analytics Project

## Overview
This project analyzes post-call borrower engagement and its relationship with Promise-to-Pay (PTP) fulfilment in a loan collection context.

## Objectives
- Analyze post-call borrower interactions and engagement.
- Explore digital touchpoints and their relationship with PTP outcomes.
- Engineer a Digital Intent Index using interactions within 24 hours of collection calls.

## Methodology
- Exploratory data analysis
- Data preprocessing and feature engineering
- Analysis of call transcripts and post-call engagement events
- Evaluation of potential indicators of PTP fulfilment

## Repository Contents
- `Outlier_outlaws.ipynb` – Jupyter Notebook containing the analysis
- `Fake_PTP_Solution_Report_.pdf` – Project report
- Supporting datasets – Input data used in the analysis, where sharing is permitted

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, and scikit-learn (where applicable).

## Note
The notebook may require the supporting datasets to be available at the expected file paths before it can be executed.
